# Point-Supervised Syllable Localization from Video

This repository contains the official PyTorch implementation of our method for point-supervised Japanese fingerspelling localization. It is based on HR-Pro and contrastive learning techniques.

This README is prepared for anonymous review. Author and institutional information has been omitted intentionally.

## Directory Structure

```bash
.
├── feature_extraction # Feature extraction pipelines(Anguler/I3D)
├── hrpro # TAL model for syllable localization
└── videomae # Point-supervised contrastive learning with VideoMAE v2
```

Each directory includes its own `README.md` with detailed instructions for setup and execution.

## Requirements

- [uv](https://github.com/astral-sh/uv)
- CUDA>=12.4
